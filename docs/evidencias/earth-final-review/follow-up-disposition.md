The native visibility experiment used a newly launched Chromium process and temporary profile on its own `xvfb-run` display, with the installed executable `/home/jefry/.cache/ms-playwright/chromium-1254/chrome-linux64/chrome` and the existing `/tmp/selene-merge-venv` Playwright environment. It connected only to that owned browser using `connect_over_cdp(no_defaults=True)` and its default context. This avoids Playwright's ordinary focus emulation rather than changing the page's visibility getters. No user/Orca/other worker browser or process was controlled. The owned browser, profile and display were closed after each test.

The test opened the real application at `http://localhost:8231/`, edited and confirmed an Atacama plan from `(-150,0)` to `(150,0)`, started the rover, explicitly inspected the baseline stop and resumed Auto. It then brought a separate tab in the same owned browser to the foreground. The page emitted `isTrusted=true`, `document.hidden=true`, `document.visibilityState='hidden'` at `08:42:43.574Z`; bringing the expedition back emitted a trusted visible event at `08:42:46.604Z`. No synthetic visibility event, controller, clock or rover-pose mutation was used.

Actual UI-generated JSON reports taken while natively hidden at `08:42:43.650Z` and `08:42:46.581Z` were exactly equal for rover pose/heading/distance/SIM/battery, path, observations/energy and inspections. Both were paused, retaining one inspection. The hidden observation interval was 2.931 real wall seconds. The report state remained paused and unchanged for a further visible interval before explicit operator resume. Resume then increased distance from `10.9312` to `18.9328` m, SIM from `13.664` to `23.666` s and modeled energy from `0.0306232920` to `0.0530138751` percent, retaining the same inspection count. The test paused and closed its run afterward.

Native-event records also include an instantaneous DOM phase label. That label can still read `running` before the window-level application handler/next render updates it; the actual exported session status in both hidden snapshots and visible-before-resume snapshots is `paused`. The proof relies on those actual report snapshots and native visibility facts, not on a stale DOM label or a frozen timer alone.

The export observer captured the Blob created by the actual export-button handler, while preventing the final native anchor download so artifacts remained scoped. It did not read or change private controller state. All browser requests outside the local preview were blocked; local telemetry/forecast/AI routes were fulfilled with explicit unavailable responses to avoid backend provider calls. The initial harness assumption that blocking a weather endpoint alone made weather unavailable was corrected after observing that fallback, and its original capture is preserved in `physics-recheck-initial-assumption.json`.
