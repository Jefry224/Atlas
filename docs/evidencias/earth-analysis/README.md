# Automatic surface and Earth analysis acceptance

The current interface replaces the empty manual Rock envelope/Marius-load workflow with source-scoped automatic regional terrain evidence. Terrain 3D has its own M2 Test Inspector and active-location Processes 72 h; destination sessions and descent reports remain separate.

Validation on 2026-11-15:

- `npm run check`: **402 JavaScript tests passed**, syntax discovery passed.
- Backend suite: **169 tests passed**, including the automatic surface DTO under all three large provider-context shapes.
- `browser.json`: **22 desktop/mobile browser checks passed** through the real UI controls and actual JSON/Markdown export Blobs. Actual WebGL rendering was active; the M2 screenshot shows its NASA bench and forces. No uncaught browser errors or unhandled rejections occurred.
- `post-review-smoke.json`: checks the final Earth thermal/geometry indicators, visible M2 inspector, inspector-before-log ordering and absence of browser errors after the last UI adjustment.
- `provider-projection.json`: projects an actual captured Earth request and verifies that all automatic surface values, Earth/reference identity and process evidence survive transport.

The browser run covers all nine M2 factors being present, factor switching, independent IDs and field/destination sessions, reference selection without moving the Earth rover, archived local forecast/table/current-hour lab, local Flight Director evidence, captured provider context, report closure, Earth-site changes, documentary La Corona context, automatically populated Marius geometry, Mars isolation, a delayed destination answer discarded after switching to Earth, and mobile fit. Pure tests also cover every published catalogue DEM and reject missing/foreign source grids.

The weather/API availability and provider responses were explicit local transport fixtures. Published data files, terrain/mission controllers and source values were not overridden. No external AI answer quality, live weather-provider availability or deployment is certified by this run.

Screenshots and exported files are actual browser artifacts. `source-sha256.json` records the feature sources and companion expedition UI/style files present in the shared local checkout. Those companion edits were preserved; they were not authored as part of this change. Earlier evidence folders remain historical snapshots of the superseded manual UI.
