# Evidencias de QA

**Se versiona:** informes `.md`, capturas `.png` y resúmenes legibles por humanos.

**No se versiona** (ver `.gitignore`): volcados de red o consola del navegador (`browser-network.json`,
`browser-console.json`), salidas masivas de `node --check` (`js-check.txt`) y JSON crudos equivalentes.

Si necesitas conservar un volcado grande, guárdalo fuera del repo o en almacenamiento del equipo.
